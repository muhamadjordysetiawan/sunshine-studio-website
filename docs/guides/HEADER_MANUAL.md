# Cara Manual Membuat Header (Jika Paste Tidak Bekerja)

## Metode 1: Ketik Manual (Paling Mudah)

Ketik satu per satu di setiap kolom:

1. **Kolom A1:** `Tanggal & Waktu`
2. **Kolom B1:** `Nama`
3. **Kolom C1:** `Email`
4. **Kolom D1:** `Telepon`
5. **Kolom E1:** `Tiket`
6. **Kolom F1:** `Jumlah`
7. **Kolom G1:** `Total`
8. **Kolom H1:** `Sesi`
9. **Kolom I1:** `Waktu Sesi`
10. **Kolom J1:** `Pertunjukan`
11. **Kolom K1:** `Metode Pembayaran`
12. **Kolom L1:** `Link Bukti Transfer`

**Cara cepat:** Klik cell, ketik, lalu tekan **Tab** untuk pindah ke kolom berikutnya.

## Metode 3: Import dari File

1. Download file CSV ini (jika tersedia)
2. Di Google Sheets: File > Import
3. Upload file CSV
4. Pilih "Replace spreadsheet" atau "Insert new sheet"

## Tips

- Gunakan **Tab** untuk cepat pindah antar kolom
- Setelah selesai, bisa **Bold** (Ctrl+B) untuk membuat header lebih jelas
- Bisa juga **Freeze** baris pertama: View > Freeze > 1 row
